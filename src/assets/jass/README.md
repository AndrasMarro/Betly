# Jasskarten-Bilder

Bilder hier ablegen, dann ersetzen sie die gezeichneten Karten automatisch. Fehlt eine Datei, bleibt die gezeichnete Karte.

- Ordner: `fr/` (französisches Blatt) und `de/` (deutsches Blatt)
- Format: `.webp`, `.png` oder `.jpg`, Hochformat ca. 5:7 (z. B. 250 × 350 px), Karte randlos zugeschnitten
- Nur Bilder verwenden, die frei genutzt werden dürfen (Public Domain / CC0 / CC BY mit Namensnennung) oder für die eine Erlaubnis vorliegt

| Blatt | Farben | Werte |
|---|---|---|
| `fr/` | `herz`, `schaufel`, `kreuz`, `ecke` | `6`, `7`, `8`, `9`, `10`, `bauer`, `dame`, `koenig`, `ass` |
| `de/` | `rosen`, `schilten`, `eicheln`, `schellen` | `6`, `7`, `8`, `9`, `banner`, `under`, `ober`, `koenig`, `ass` |

Dateiname: `<farbe>-<wert>`, zum Beispiel `fr/herz-koenig.png`, `fr/ecke-10.webp`, `de/rosen-under.jpg`.
36 Dateien pro Blatt.
